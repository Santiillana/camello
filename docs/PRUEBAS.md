# Pruebas CAMELLO

## Automatizadas

- `npm run verify`: dependencias, audit, lint, base de datos y build.
- `npm run verify:db`: base nueva, migraciones, conteos/totales, enteros COP, anti-duplicado, rollback y foreign keys.
- `scripts/verify-ui-c1.mjs`: menú lateral, barra inferior, + flotante y ancho escritorio.
- Instrumented Android: reproducción de transacción anidada con plugin real.

## Manuales

GPS real, precisión, cámara, ubicación pegada desde WhatsApp, compartir archivo, instalar encima de versión anterior y cerrar/apagar teléfono permanecen en guía manual.

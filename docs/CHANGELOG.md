# Changelog

## 1.0.0

- Endurecimiento de TypeScript.
- Migraciones SQLite v2-v14 con transacciones individuales.
- Verificación de integridad, rollback y fixtures.
- Vitest para los 9 escenarios obligatorios.
- E2E Playwright integrado en `npm run verify`.
- ErrorBoundary de raíz con recuperación y exportación de respaldo.
- Corrección del marcador local de `UbicacionMiniMapa`.
- Mapa sin dependencia del icono raster remoto de Leaflet.
- Respaldo/restauración con checksum y respaldo cifrado.
- CI de verify, E2E, supply-chain y APK.
